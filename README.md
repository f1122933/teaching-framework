# C++ / 数据结构与算法 · 讲解框架

> 一套面向 C++ 与数据结构算法（DSA）的**讲解组织方法**——讲完的目标不是"讲得清楚"，而是对方以后**能自己判断**。
> 版本：v1.2.0 ｜ 建立：2026-10-12 ｜ 状态：生效中

## 这是什么

一套经过实践打磨的讲解框架，用于组织 C++ / 数据结构与算法概念的讲解。三条核心主张：

1. **讲完的标准是"能判断"**——"它在解决什么问题、为什么这里会出现它、这个方案是否合理"，而不是背出定义。
2. **短优先**——一个概念 = 一句结论 + 一张对比表 + 一段代码；一屏之内读完；并列不超过 5 条。
3. **默认直给结论**——引导式提问只在对方想自己推导时使用。

## 六步框架

| # | 步骤 | 一句话 |
|---|---|---|
| 1 | 定位 | 只答对方卡住的那一层，第一句给结论 |
| 2 | 立问题 | 先讲"为什么需要它"——没有它会怎样 |
| 3 | 直觉入口 | 一个类比 + 立即声明它的失效边界 |
| 4 | 机制 | 递进展开、状态可见、可跑代码，不留未解释的行 |
| 5 | 取舍 | 给对比表：解决什么 / 何时用 / 何时不用 / 什么成本 / 替代方案 |
| 6 | 收尾 | 误区 + 30 秒自测 + 一句话复述 |

完整内容（含执行协议、硬约束、模式库、句式模板、真实踩坑清单、来源清单）见 **[讲解框架.md](./讲解框架.md)**。
